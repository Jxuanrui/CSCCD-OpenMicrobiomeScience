# microbiome-multiomics-batch：多中心数据整合与批次校正

## 职责

专门处理来自多个中心、不同测序平台或不同批次的菌群数据整合问题，这是大型菌群研究的关键技术难点。

（原草稿中的 microbiome-multicenter 功能，扩展并重命名以更准确反映职责范围）

## 批次效应来源识别

| 来源 | 影响程度 | 识别方法 |
|------|---------|---------|
| 测序平台（Illumina HiSeq vs MiSeq vs MGI） | 高 | PCoA 按平台着色 |
| 引物区段（V3-V4 vs V4 vs V1-V3） | 极高 | 属级注释覆盖率差异 |
| DNA 提取方法 | 中-高 | 已知标准品测试 |
| 测序深度差异 | 中 | 稀释曲线比较 |
| 不同批次试剂 | 低-中 | 阴性对照监控 |

## 批次效应校正方法

### 菌群专用方法
- **MMUPHin**（推荐）：针对宏基因组/16S 数据，meta 分析框架
- **ConQuR**：基于零膨胀模型，较新，处理稀疏性更好

### 通用方法（慎用于菌群）
- **ComBat-seq**：适合连续型数据，菌群需转换后使用
- **Harmony**：适合降维后的嵌入空间

### 不应该做的
- 不能合并 V3-V4 和 V4 数据（引物区段不同，无法直接比较）
- 不能将不同分类层级（属级 vs 种级）的数据合并

## 跨中心验证设计

### Leave-one-center-out 交叉验证
```
n 个中心 → 每次用 n-1 个训练，1 个测试
→ 最终报告 n 次测试结果的平均 AUC（置信区间）
```

### Meta 分析整合
- 每个中心独立分析，汇总效应量（OR/HR + 95%CI）
- 随机效应模型（异质性大时）/ 固定效应模型（异质性小时）
- I² 统计量评估异质性（> 50% 需谨慎解读合并结果）

## 分类层级一致性检查
- 确认所有数据集使用相同的参考数据库（SILVA / GTDB / Greengenes2）及版本
- 在最低公共层级（通常是属级）分析
- 种级分析仅在测序深度和数据库覆盖度均充分时进行

## 调用关系
- 批次校正后进行分析 → `microbiome-bioinformatics`
- 异质性大时的统计策略 → `microbiome-stats`
- 写作时批次效应处理说明 → `microbiome-writing`
