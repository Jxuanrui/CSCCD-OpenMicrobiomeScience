# microbiome-writing：菌群论文写作

## 职责

将菌群分析结果组织成结构严谨、表达准确的学术论文，覆盖 Methods → Results → Discussion 全链条。

## 各章节写作要点

### Methods（方法）
标准结构：
1. 研究对象与伦理（队列、纳排标准、伦理批号）
2. 样本采集（采样时间、保存方式、运输条件）
3. DNA 提取与测序（提取试剂盒、测序平台、测序参数）
4. 上游生信（质控工具版本 + 参数、OTU/ASV 构建）
5. 下游统计（多样性指数、差异分析方法、多重检验矫正方式）
6. 机器学习（如有）：特征预处理、模型选择、验证策略、防泄漏措施

**常见漏项**：未说明引物序列、未说明稀释策略、软件版本缺失

### Results（结果）
递进结构（推荐）：
1. 队列基本特征描述（Table 1）
2. 整体群落景观（alpha/beta 多样性）
3. 组间差异物种/功能（差异分析结果）
4. 预测模型性能（如有）
5. 多组学关联（如有）
6. 亚组或敏感性分析

**表述规范**：
- 报告统计量 + 效应量 + 校正后 p 值
- 图表数据与正文数字必须一致
- 避免在 Results 中写解释性语言（放 Discussion）

### Discussion（讨论）
结构：
1. 主要发现总结（1段，不重复 Results）
2. 与已有文献比较（支持 / 补充 / 矛盾，需引用）
3. 机制解释（谨慎，相关性不等于因果）
4. 研究局限性（诚实列举）
5. 临床或科研意义

## 高频表述错误纠正
- ❌ "A 菌增加导致了 B 疾病" → ✅ "A 菌与 B 疾病的发生显著正相关"
- ❌ "粪便菌群反映了肠道菌群" → ✅ "粪便菌群是肠道菌群的部分体现，不能完全代表原位菌群"
- ❌ "我们证明了…" → ✅ "我们的结果提示…" / "我们观察到…"
